# بصيرة · مختبر كريبتو تعليمي

مشروع مبني على **Freqtrade الأصلي**، يراقب BTC وETH ويشرح الإشارات بالعربية ويسجل نتائج تداول وهمي قابل للمراجعة.

الفكرة: ربط قرار قابل للتفسير بنتيجة قابلة للقياس. لا يقدم المشروع وعدًا بالربح، ولا يستخدم نموذج ذكاء اصطناعي للتنبؤ بالسعر؛ الإشارات مبنية على قواعد رياضية واضحة.

## مساهمتي في المشروع

إعداد Freqtrade داخل Docker، وإضافة استراتيجية تعليمية ومحتوى عربي للإشارات، وتنظيم الربط المحلي بتيليجرام، وكتابة الاختبارات والتوثيق. محرك التداول نفسه من مشروع Freqtrade ومساهميه. جرى التنفيذ بمساعدة أدوات الذكاء الاصطناعي.

## التشغيل

بعد تثبيت Docker وPython 3، افتحي الطرفية داخل المستودع وشغلي:

```sh
python3 setup.py
docker compose pull
docker compose up -d
docker compose logs --tail 50 -f
```

أدخلي التوكن في نافذة الإعداد المحلية فقط؛ لن تظهر حروفه. يمكن تركه فارغًا للعمل دون تيليجرام. لا ترفعي مجلد `private` إلى أي مستودع. لا يحتاج المشروع مفتاح منصة أو محفظة.

انتظري ظهور RUNNING ورسالة تؤكد وضع المحاكاة. أرسلي `/status` إلى بوتك للصفقات، و`/profit` للأداء، و`/daily` لملخص الأيام. أمر `docker compose stop` يوقف التشغيل. يجب أن يبقى الجهاز مستيقظًا وDocker يعمل.

## حدود واضحة

- رصيد 1000 دولار افتراضي، وحجم صفقة 100 دولار، وبحد أقصى صفقتين.
- شموع ساعة، ومتوسطان 20 و50 ساعة وRSI بسيط لـ14 ساعة.
- رسوم افتراضية 0.26% لكل جانب، وحد خسارة 3% وهدف عائد 6% وفق حسابات Freqtrade.
- ليست محاكاة مطابقة للتنفيذ الحقيقي؛ الانقطاع والفجوات قد يتجاوزان حدود الخروج.
- يوجد سجل تشغيل فعلي للمحاكاة، لكن لم يكتمل تقييم الربحية التاريخية وخارج العينة.
- بعض رسائل Freqtrade الأصلية بالإنجليزية؛ رسائل شرح الاستراتيجية بالعربية.
